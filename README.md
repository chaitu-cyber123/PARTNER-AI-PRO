# 🤖 Partner AI

> An advanced personal AI assistant built with Python, voice control, memory, automation, and AI capabilities.

## 🌟 Overview

Partner AI is a personal assistant project designed to provide a smart voice-controlled experience. It combines speech recognition, AI conversations, long-term memory, Android app control, reminders, and automation features.

## 🚀 Features

### 🎤 Voice System
- Voice input using Android Speech-to-Text
- Voice responses using Android Text-to-Speech
- Hands-free interaction

### 🧠 AI Brain
- Powered by OpenRouter API
- Natural language conversations
- Programming and study assistance
- Professional assistant personality

### 💾 Long-Term Memory
- Stores user preferences
- Remembers important information
- JSON-based memory storage

### 📱 Android Control
Voice commands to open:
- YouTube
- Chrome
- WhatsApp
- Gmail
- Settings

### 📝 Notes & Reminders
- Create notes by voice
- Save reminders
- Retrieve saved information

### ⚙️ Automation
Custom modes:
- Good morning routine
- Study mode
- Entertainment mode
- Shutdown mode

### 🖥️ System Information
- Time and date
- Battery status
- System status reports
